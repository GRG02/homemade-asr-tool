================================================================================
ข้อกำหนดของระบบและการตั้งค่าเครื่องปลายทาง (Machine Setup & Prerequisites)
สำหรับโปรเจกต์ Speech-to-Text (Pathumma FastConformer RNN-T)
================================================================================

สิ่งที่ต้องติดตั้งหรือตั้งค่าเพิ่มเติมบนเครื่องปลายทาง (นอกเหนือจาก Python Packages ใน requirements.txt)
เพื่อให้โปรแกรมทำงานได้อย่างสมบูรณ์:

--------------------------------------------------------------------------------
1. ซอฟต์แวร์ระบบพื้นฐาน (System Runtimes)
--------------------------------------------------------------------------------
[1.1] Python 3.10 หรือ 3.11 (64-bit)
    - ต้องเป็นรุ่น 64-bit เท่านั้น
    - ข้อสำคัญ: ในขั้นตอนติดตั้ง ต้องติ๊กเลือกช่อง "Add python.exe to PATH"
    - ลิงก์ดาวน์โหลด: https://www.python.org/downloads/

[1.2] Microsoft Visual C++ 2015-2022 Redistributable (x64)  **สำคัญมาก**
    - จำเป็นสำหรับ PyTorch, SoundDevice, SentencePiece และ NeMo C++ Kernels
      (หากไม่มีตัวนี้จะขึ้น Error หาไฟล์ MSVCP140.dll หรือ VCRUNTIME140.dll ไม่เจอ)
    - ลิงก์ดาวน์โหลดตรงจาก Microsoft:
      https://aka.ms/vs/17/release/vc_redist.x64.exe

--------------------------------------------------------------------------------
2. ข้อกำหนดด้านฮาร์ดแวร์และไดรเวอร์ (Hardware & Drivers)
--------------------------------------------------------------------------------
[2.1] การ์ดจอ NVIDIA และไดรเวอร์ (สำหรับเร่งความเร็วด้วย GPU)
    - แนะนำการ์ดจอ NVIDIA สถาปัตยกรรม Pascal ขึ้นไป (GTX 1060+) 
      และแนะนำระดับ RTX Series (RTX 20/30/40) เพื่อประสิทธิภาพ bfloat16 สูงสุด
    - ต้องติดตั้ง NVIDIA Driver รุ่นมาตรฐานให้พร้อมใช้งาน
    - หมายเหตุ: *ไม่ต้องติดตั้ง CUDA Toolkit แยกต่างหาก* เนื่องจาก PyTorch 
      มี CUDA Runtime Library ฝังมาในตัวเองเรียบร้อยแล้ว
    - (หากไม่มีการ์ดจอ NVIDIA ระบบจะสลับไปรันบน CPU แต่ความเร็วจะช้าลง)

[2.2] อุปกรณ์บันทึกเสียง (Microphone)
    - ต้องมีไมโครโฟนต่ออยู่กับเครื่องและตั้งเป็น Default Recording Device

--------------------------------------------------------------------------------
3. การตั้งค่าสิทธิ์บน Windows (Windows Permissions)
--------------------------------------------------------------------------------
[3.1] สิทธิ์การเข้าถึงไมโครโฟน (Microphone Privacy Settings)
    - ไปที่: Settings > Privacy & security > Microphone
    - ตรวจสอบให้แน่ใจว่าเปิด:
      * "Microphone access" = On
      * "Let desktop apps access your microphone" = On

[3.2] สิทธิ์ผู้ดูแลระบบ (Run as Administrator - เสริม)
    - ปุ่มลัด Win + Z ทำงานได้ตามปกติในทุกแอปทั่วไป
    - หากต้องการให้พิมพ์ข้อความอัตโนมัติลงในโปรแกรมที่เปิดแบบสิทธิ์แอดมิน 
      (เช่น Task Manager, Registry Editor, หรือ CMD ที่เป็น Run as admin) 
      จะต้องเปิด start.bat ด้วยการคลิกขวาแล้วเลือก "Run as administrator" เช่นกัน

--------------------------------------------------------------------------------
4. การเชื่อมต่อเครือข่าย (Network Access)
--------------------------------------------------------------------------------
    - ต้องต่ออินเทอร์เน็ตสำหรับการเปิดโปรแกรม "ครั้งแรกเท่านั้น"
    - โปรแกรมจะดาวน์โหลดไฟล์โมเดล Pathumma (ขนาดประมาณ 2.4 GB) 
      จาก Hugging Face หรือ Hugging Face Mirror อัตโนมัติ
    - หลังจากดาวน์โหลดเสร็จสมบูรณ์ในครั้งแรกแล้ว ครั้งต่อไปสามารถตัดเน็ต
      และใช้งานแบบออฟไลน์ (Offline 100%) ได้ทันที

--------------------------------------------------------------------------------
5. ขั้นตอนการติดตั้งครั้งแรกบนเครื่องใหม่ (Quick Installation Steps)
--------------------------------------------------------------------------------
เปิด Command Prompt (CMD) ที่โฟลเดอร์โปรเจกต์ แล้วรันคำสั่งตามลำดับ:

1. สร้าง Virtual Environment:
   python -m venv .venv

2. อัปเกรด pip:
   .venv\Scripts\python.exe -m pip install --upgrade pip

3. ติดตั้ง Dependencies ทั้งหมด:
   .venv\Scripts\python.exe -m pip install -r requirements.txt

4. รันโปรแกรม:
   ดับเบิลคลิกที่ start.bat
